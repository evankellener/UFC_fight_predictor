How It Works

This model predicts UFC fights using 200 features built from every fighter's career stats. It combines a custom Elo rating system (tuned for MMA with KO/submission multipliers, inactivity decay, and opponent quality scaling) with smoothed fight statistics (striking, grappling, defense) and style matchup interactions that capture how different fighting styles match up against each other.

The model trains on ~3,100 UFC fights from 2018-2024 and predicts by comparing two fighters across all 200 dimensions, weighted by how predictive each stat has been historically.
